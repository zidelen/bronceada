MAKE BRAND CONTENT EDITABLE IN THE THEME EDITOR — ROUND 2
=========================================================================

CONTEXT
-------
Round 1 (shipped separately) added image_picker settings to 6 sections so
hardcoded photos could be swapped from the theme editor: hero, category-grid,
about-main, our-story-iwt, community-iwt, footer.

The client is actively editing the site (templates/index.json shows they've
already rewritten several section defaults), so this round expands editability
to everything else tied to their BRAND and BUSINESS — copy, store info, links,
and brand colors — while leaving the THEME itself (layout, CSS, structure,
fonts) locked to code. Policy pages, the 404 page, favicon plumbing, and
seo-schema.liquid were explicitly kept out of scope.

Per-section settings, no shared/global settings: every value (including
colors) lives on the section that renders it. Changing the brand yellow
everywhere means editing it in each of the ~8 sections that use it — a
deliberate tradeoff in exchange for full per-section control.

IMPLEMENTATION NOTES
---------------------
- Shopify's {% stylesheet %} tag does NOT evaluate Liquid (confirmed: zero
  files in this ~300-file theme interpolate inside one). Color settings are
  injected as CSS custom properties via an inline `style` attribute on each
  section's root element (the same pattern round 1 already used for
  `--bftr-bg`), and the {% stylesheet %} block references
  `var(--color-x, #fallback)` with the fallback equal to today's hex — visual
  output is unchanged until a merchant edits the color in the editor.
- about-main.liquid has multiple sibling top-level elements (no single
  wrapper), so its color variables are emitted once via a small inline
  `<style>` block scoped to its section classes, rather than repeating an
  inline style attribute on every element.
- Footer/category-grid links and collections fall back to today's hardcoded
  path when the new setting is blank, so nothing breaks if a field is cleared
  without a replacement value.
